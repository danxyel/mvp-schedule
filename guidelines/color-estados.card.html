Estados de Reserva

Mapeo de estados de reserva a tonos del sistema Vértice. El sistema no define color de error; los estados inactivos usan tone idle.

Confirmada
TONE: positive
Confirmada
Reserva confirmada y lista. El usuario ya está inscrito y debe asistir a la sesión.
badgeClassForEstado('confirmada')
En Espera de Pago
TONE: warn
En espera
Reserva propuesta que requiere confirmación de pago. El usuario debe completar la acción de pago.
badgeClassForEstado('en_espera')
Procesando
TONE: idle
Procesando
Reserva en proceso. Será confirmada por el administrador. No requiere acción del usuario.
badgeClassForEstado('pendiente')
Completada
TONE: idle
Completada
Sesión finalizada exitosamente. El usuario ya asistió y se completó la actividad.
badgeClassForEstado('completada')
Cancelada
TONE: idle
Cancelada
Reserva cancelada. El usuario no asistirá. No requiere acción adicional.
badgeClassForEstado('cancelada')
No Asistió
TONE: idle
No asistió
Usuario no asistió a la sesión confirmada. Se registra la inasistencia en el sistema.
badgeClassForEstado('no_show')

Implementación en Frontend

Utiliza las funciones del módulo frontend/src/utils/estado.js para aplicar estilos consistentes:

// Importar funciones del módulo de estado import { badgeClassForEstado, badgeClassForTone } from '../utils/estado' // Para un estado de reserva <span className={badgeClassForEstado(r.estado)}> {ESTADO_LABEL[r.estado]} </span> // Para un tono específico <span className={badgeClassForTone('positive')}> Disponible </span>
Principios de aplicación:
  • Un solo color para cada trabajo semántico
  • Mantener consistencia visual en toda la app
  • No inventar nuevos colores fuera del sistema
  • Usar las constantes y funciones centralizadas
